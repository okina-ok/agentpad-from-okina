## 1. 这是什么

AgentPad 是一块 AI 工作状态键盘，用来"一眼看清你的 AI 们都在干嘛"：

- **6 个频道键**：对应 6 个 Codex 对话，灯光实时显示每个对话的状态
- **命令键**：接受 / 拒绝 / 新建 / 分支 / 停止 / 重试 / 语音（PTT）
- **屏幕**：显示每个频道对应哪个对话、当前状态
- **语音输入**：按住语音键说话，松开自动转成文字填进输入框

它不替代你的主键盘，是放在旁边的一块"AI 状态窗 + 遥控器"。

## 4. 首次使用：环境自检

> 目标：5 分钟内确认"缺什么、装什么"。以下每一步都有"通过标准"，
> 没通过的那一步就是你需要装的东西。

### 4.1 检查 Python

打开 PowerShell（按 `Win` 键，输入 powershell，回车），粘贴：

```powershell
python --version
```

- 显示 `Python 3.10+` 之类 → 通过
- 提示"不是内部或外部命令" → **去 [python.org](https://www.python.org/downloads/) 下载安装**，
  安装时**务必勾选 "Add Python to PATH"**

### 4.2 检查 Python 依赖包

```powershell
pip show pyserial faster-whisper sounddevice pywinauto pyperclip
```

- 每个包都显示版本信息 → 通过
- 有包提示"WARNING"或没找到 → 运行安装：

```powershell
pip install pyserial faster-whisper sounddevice pywinauto pyperclip
```

### 4.3 检查语音模型文件（语音功能需要）

检查模型文件是否存在（路径在安装目录下）：

```powershell
Test-Path whisper-small\model.bin
```

- 显示 `True` → 通过
- 显示 `False` → 下载模型（约 460MB）放到 `whisper-small/model.bin`：

```powershell
Invoke-WebRequest -Uri "https://hf-mirror.com/Systran/faster-whisper-small/resolve/main/model.bin" -OutFile whisper-small\model.bin
```

> 只想要状态灯、不需要语音功能的话，这步可以跳过。

### 4.4 检查 Codex 日志库

```powershell
Test-Path "$env:USERPROFILE\.codex\logs_2.sqlite"
```

- 显示 `True` → 通过（Codex 已正常使用过）
- 显示 `False` → 先打开 Codex 用一次再回来

### 4.5 检查键盘连接（插上键盘后）

## 5. 安装与启动

### 5.1 安装

1. 安装 Python（见 4.1）
2. 安装依赖包（见 4.2）
3. 下载语音模型（可选，见 4.3）
4. 把产品文件夹放到你喜欢的目录（比如 `D:\AgentPad\`）
5. 用 USB 线连接键盘

### 5.2 启动

双击桌面上的 **「AgentPad 启动」**，会依次拉起：

1. 状态守护进程（读取 Codex 状态，驱动灯光）
2. 实体键盘（免驱动，即插即用）

**验证**：键盘灯亮起、屏幕显示你的对话列表，即启动成功。

> 没有实体键盘时，可以用模拟器预览效果：
> `python simulator.py`

### 5.3 关闭

- 拔掉键盘即可（守护进程会自己退出）
- 或者任务管理器里结束 `status_daemon.py` / `guard_daemon.py`

## 6. 产品操作

### 6.1 灯色含义

| 颜色 | 含义 |
| --- | --- |
| 紫（呼吸） | AI 正在思考 |
| 青（常亮） | AI 正在跑工具/干活 |
| 琥珀（闪烁） | 在等你操作/审批 |
| 绿（常亮） | 已完成 |
| 红（闪烁） | 出错 |
| 灰（熄灭） | 空闲/没活动 |

### 6.2 频道键（最重要）

**6 个频道键 = 你最近在用的 6 个 Codex 对话。**

- 灯的亮灭 = 那个对话当前的状态（见 6.1）
- 频道 1 是主频道：**固定不换**，默认是你最主要的对话
- 其余频道按"最近活跃"自动分配，分配后**不再乱跳**
- 没有第 5、6 个对话时，5/6 频道是空的（灰色）——正常现象

### 6.3 命令键

| 按键 | 功能 | 状态 |
| --- | --- | --- |
| 接受 / 拒绝 | 审批弹窗时一键确认/否决 | 【待定：功能实现后填写】 |
| 新建 | 开一个新对话 | 【待定】 |
| 分支 | 从当前对话分支出去 | 【待定】 |
| 停止 | 让当前 AI 停止干活 | 【待定】 |
| 重试 | 重新执行上一步 | 【待定】 |
| 语音（PTT） | 按住说话，松开转文字进输入框 | 已实现（PC 侧） |

### 6.4 旋钮

- 旋转：滚动浏览 AI 的长输出
- 按下：【待定】

### 6.5 语音输入（PTT）

1. 按住语音键，开始说话
2. 松开，约 2–4 秒后文字自动出现在 Codex 输入框
3. 检查文字没问题后，回车发送

> 转写全程本地离线，不联网；识别不准时请口齿清楚一点，或稍后版本优化。

## 7. 频道绑定与切换（重点）

### 7.1 什么是"绑定"

"绑定"= 决定**哪个对话显示在哪个频道键上**。

默认全自动，你也可以手动指定，两种方式任选：

### 7.2 方式一：图形面板（推荐）

1. 双击桌面 **「AgentPad 绑定面板」**（或运行 `python bind_panel.py`）
2. 窗口里列出 6 个频道，每个频道右侧是下拉框：
   - 选「自动」= 让程序自己分配
   - 选某个对话 = 手动绑定到该频道
3. 点 **保存绑定**
4. 约 1 秒后键盘/模拟器生效

### 7.3 方式二：直接改配置文件

打开产品目录下的 `channel_map.json`：

```json
{
  "manual": { "2": "019fcad7-39f0-7812-a12a-cb857e9a6136" },
  "auto": { "1": "019fd6a2-46d2-7310-af72-582411385d96" }
}
```

- `manual`：你手工绑定的频道 → 对话 ID
- `auto`：程序自动分配的（不用动它）
- 保存后同样约 1 秒生效

> 对话 ID 在哪看？绑定面板的对话列表里每个对话后面括号里就是
> （形如 `019fcad7-39f0-…`）。

### 7.4 频道切换

切换 = 让 Codex 跳到某个对话。

【待定：实体硬件实现切换后填写——预期为"按一下频道键，Codex 自动切到那个对话"；
当前版本切换仍需在 Codex 窗口手动点击】

### 7.5 常见疑问

- **为什么某频道是灰的？** 那个对话最近没有活动。灰色=空闲，不是坏了。
- **为什么 5/6 频道是空的？** 你只有 4 个对话，6 个槽没填满。
- **怎么把 A 对话固定到 3 号键？** 绑定面板里 3 号频道选 A，保存。
- **绑定后对话换名字了？** 绑定的是"对话"，不是"名字"，名字变了绑定不变。

## 8. 故障排查

| 现象 | 排查 |
| --- | --- |
| 灯完全不亮 | 1) USB 是否插好 2) 守护进程是否在跑 3) 看设备管理器有无异常设备 |
| 灯不更新 | 1) Codex 是否开着 2) 4.4 日志库检查是否通过 |
| 语音没反应 | 1) 4.3 模型文件 2) Windows 麦克风权限是否允许 |
| 语音识别不准 | 模型是本地小模型，长句/生僻词易错；语速放慢 |
| 频道对不上 | 打开绑定面板重新绑定 |
| 守护进程闪退 | 运行 `python status_daemon.py` 看报错，截图发给客服 |

## 9. 注意事项

- AgentPad 通过读取 Codex 的本地日志来感知状态，**Codex 升级后可能短暂失效**，
  属已知情况，更新产品版本即可
- 语音转写在本地完成，不上传；请勿在公共电脑使用
- 本产品与 OpenAI 无隶属关系
